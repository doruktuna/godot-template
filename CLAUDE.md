# Working Preferences

This is a learning project. The goal is for me to understand and write the code myself.

## How to help
- Suggest code changes instead of editing files directly.
- Don't give copy-paste-ready solutions. Explain the approach and the relevant Godot/GDScript concepts. Point me to the right APIs, nodes or patterns, and use short illustrative snippets or pseudocode where they help.
- Before making any change, explain what you plan to change and why, then wait for my explicit permission.
- When reviewing my code, point out problems and explain the reasoning. Let me write the fix.
